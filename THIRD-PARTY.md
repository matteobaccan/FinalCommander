## Rust dependencies

All current dependencies are permissively licensed (MIT, Apache-2.0, BSD, ISC, Unlicense,
Unicode-3.0, or MPL-2.0 at file level). The policy and the allow-list live in `deny.toml`;
`cargo deny check licenses` enforces it in CI.

| Crate | Licence | Why we use it |
| --- | --- | --- |
| `crossterm` | MIT | the terminal backend: input decoding, raw mode, painting |
| `tokio` | MIT | the async runtime for filesystem and (later) network work |
| `chrono` | MIT OR Apache-2.0 | local-time formatting in panel columns |
| `clap` | MIT OR Apache-2.0 | the command line |
| `serde`, `toml` | MIT OR Apache-2.0 | configuration, keymaps and themes |
| `fluent-bundle`, `unic-langid` | Apache-2.0 OR MIT | localisation catalogues |
| `globset` | Unlicense OR MIT | selection masks (`*.rs,*.toml`) |
| `unicode-width` | MIT OR Apache-2.0 | correct double-width (CJK) layout |
| `thiserror`, `anyhow` | MIT OR Apache-2.0 | error types |
| `dirs` (and `option-ext`, MPL-2.0) | MIT OR Apache-2.0 | per-OS configuration directories |
| `async-trait` | MIT OR Apache-2.0 | the `Vfs` trait |
| `tempfile` (dev only) | MIT OR Apache-2.0 | filesystem tests |

Two dependencies are multi-licensed with a copyleft option we do **not** take: `r-efi`
(we use MIT) and `self_cell` (we use Apache-2.0).
